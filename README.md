# AI English Voice Coach

A mobile-first web app that helps people working in tourism communicate more clearly and confidently in English.

The idea was inspired by conversations with drivers, hosts, and local workers in **Bali and Lombok**, where English can be a barrier in daily communication with tourists.

This is a **personal learning project** combining frontend development, AI, education, and social impact.

---

## ✨ What it does

- Users type a sentence they want to say in English
- The app:
  - corrects the sentence naturally
  - keeps it simple and polite
  - explains the correction in very basic English
- (Next step) plays a human-sounding voice to hear correct pronunciation

The focus is on **practical English people can use immediately**, not grammar theory.

---

## 🛠 Tech stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- API Routes
- AI services (in progress)
